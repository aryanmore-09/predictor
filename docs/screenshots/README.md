# Screenshots

Add the following images to this folder (they are referenced by the root `README.md`):

| File | Screen |
|---|---|
| `login.png` | Login page |
| `student-dashboard.png` | Student dashboard (risk trend + what-if simulator) |
| `admin-dashboard.png` | Admin analytics / model registry |
| `faculty-dashboard.png` | Faculty advisor dashboard |

**Tips**

- Capture at roughly **1600 × 900**, in the default (light) theme.
- Crop out the browser chrome so the screenshot is just the app.
- Use PNG for crisp text.
- To avoid committing broken images, add all four before pushing.
